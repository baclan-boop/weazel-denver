# Бесплатный доступ для пользователей РФ через Cloudflare Workers

Этот воркер — прозрачный реверс-прокси: пользователь заходит на адрес
`*.workers.dev` (сеть Cloudflare), воркер пересылает запрос на настоящий
Render и отдаёт ответ обратно. Бесплатно, домен покупать не нужно.

## Шаг 1. Завести аккаунт

1. Зайти на **dash.cloudflare.com** → зарегистрироваться (email + пароль).
   Банковская карта не требуется — бесплатный тариф Workers не просит оплату.

## Шаг 2. Создать воркер

1. В левом меню: **Workers & Pages** → **Create** → **Create Worker**.
2. Дать любое имя (например `weazelnews`) — оно станет частью адреса:
   `https://weazelnews.ВАШ-САБДОМЕН.workers.dev`
3. Нажать **Deploy** (сначала создастся с шаблонным кодом — это нормально,
   код заменим на следующем шаге).

## Шаг 3. Вставить код

1. Открыть созданный воркер → **Edit code** (или значок редактора).
2. Полностью стереть содержимое редактора и вставить весь код из файла
   `worker.js` (лежит рядом с этим README).
3. **Проверить строку `const ORIGIN = ...`** — там должен стоять ваш
   настоящий адрес Render (`https://wn-dn.onrender.com` уже подставлен;
   если у вас другой — поменяйте).
4. Нажать **Save and deploy**.

## Шаг 4. Проверить

1. Открыть выданный адрес `https://ИМЯ.САБДОМЕН.workers.dev` в браузере —
   сайт должен открыться и работать так же, как на прямом Render-адресе
   (включая вход, публикацию новостей, загрузку картинок).
2. **Главное** — попросить кого-то из пользователей РФ, у кого сайт не
   грузился, открыть именно этот новый адрес. Если заработало — можно
   давать эту ссылку всей русской аудитории вместо прямой ссылки на Render.
   Если по-прежнему не работает — см. примечание ниже.

## Если не поможет

Это способ №1 из списка вариантов (CDN/прокси с другим диапазоном IP).
Если блокировка идёт не по IP-диапазону Render, а как-то иначе — этот
способ может не сработать, и тогда единственный практичный вариант —
переезд бэкенда на российский хостинг (обсуждали в переписке) либо VPN
для пользователей.

## О лимитах

Бесплатный тариф Cloudflare Workers — 100 000 запросов в день. Для такого
проекта, как этот, этого с большим запасом достаточно. Если когда-нибудь
станет мало — следующий шаг стоит $5/мес (Workers Paid), но это уже не
бесплатный вариант.
